Hi everyone, I'm a postdoc in Dr. Gregory Corder's lab and I'm sharing my instructions for creating UCLA miniscope integrated Baseplate + GRIN lens, plus a .psd file that you can download and modify for your purpose, using Miniscopeparts.com baseplates, a great small business run by Shylo Stiteler. The .psd file I have included is for a 1mm GRIN lens, so if you want to use a different diameter, please feel free to modify the radius and discuss with Shylo and he can modify the baseplates. If you want to contact Shylo please email him at shylostiteler at gmail.com.
